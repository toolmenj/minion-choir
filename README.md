# 小小兵合唱團

一排 3D 角色站在舞台上，會自己動、會看滑鼠，點誰誰就接著唱下一句；也可以讓整團把一首歌從頭唱完（獨唱、二重唱、三重唱輪流，最後一句大合唱）。

整個專案只有一個網頁（`index.html`），用 three.js 畫 3D、用 Web Audio 發聲，沒有後端。

## 這個儲存庫不含 3D 模型

角色模型有版權，沒有放進來。要讓頁面跑起來，請自行準備模型放到 `models/` 資料夾：

- 格式：GLB，含骨架。
- 骨架：3ds Max Biped 命名（`Bip001_Pelvis`、`Bip001_Head`、`Bip001_JAWL`…），程式靠這些骨頭名稱做轉頭、張嘴、站位校正。
- 檔名與要用哪些動作，在 `index.html` 的 `MODELS` 表裡設定。
- 沒有骨架的模型也能放（`static: true`），但只會整隻跳和轉身，嘴巴和手不會動。

## 怎麼開

模型檔要透過本機伺服器載入，直接雙擊 `index.html` 會被瀏覽器擋下來。

```
start.bat
```

或自己執行 `python -m http.server 8765 --bind 127.0.0.1`，再開 <http://127.0.0.1:8765/index.html>。需要網路（three.js 從 CDN 載入）。

## 怎麼玩

- **點角色**（或按數字鍵 1–9）：他獨唱目前這首歌的下一句。
- **▶ 合唱**：整團自動唱完整首。
- **✎ 簡譜**：看或修改樂譜、換調、調速度；歌曲選單選「自己貼簡譜」可以貼自己的歌。
- **⏺ 錄影**：把整首合唱錄成 webm 影片下載。
- 連續狂點同一隻他會抓狂，每隻的忍耐度不同。

### 簡譜格式

| 寫法 | 意思 |
|---|---|
| `1`–`7`、`0` | Do–Si、休止 |
| `[1]`、`(5)` | 高八度、低八度 |
| `#4`、`b7` | 升、降 |
| `-` | 延長一拍 |
| `_`、`__` | 半拍、四分之一拍 |
| `.` | 附點 |
| `~` | 連結線（接在前一個同音後面不重唱） |
| `{-3}` | 從這裡開始整體降 3 個半音（轉調） |

空白和 `|` 只是方便閱讀。內建的歌都是沒有版權問題的老歌。想加只留在自己電腦上的歌，建立 `songs.local.js`（已被 `.gitignore` 排除）：

```js
export default {
  '歌名': { bpm: 100, key: 0, score: '1 2 3 4 | 5 - - -' },
};
```

## 聲音是怎麼來的

`voice/` 裡是人聲取樣庫，由 `tools/build_voice_bank.py` 產生。九隻角色各用一個不同的底聲：

1. 用 [Kokoro](https://github.com/hexgrad/kokoro)（本機語音合成）的九個不同聲音，各唸一批單音節（Bah、Nah、Mee…）。
2. 整體加速，讓音高和嗓音一起變尖。
3. 沿著聲帶的每次振動把母音切成小片，再照目標音高重新排列，延長成可以循環的長音。
4. 把音量拉平：說話的母音剛開口時比較小聲，循環時也會忽大忽小，不處理的話唱起來會斷斷續續。
5. 品管：每個取樣做完都量一次音高和平穩度，不合格的不收。

網頁播放時依照量到的頻率換算播放速度，所以音準是準的。同一句裡的音會重疊銜接、音高用滑的、長音加上抖音和氣音；嘴型跟著音節的母音走，身體動作對著節拍。

取樣庫載入失敗時會退回純合成音；網址加 `?synth` 可以強制用合成音。

重建取樣庫需要 `pip install kokoro-onnx soundfile numpy`、ffmpeg，以及 Kokoro 的模型檔。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 全部的程式：3D 場景、動作、互動、發聲、點歌、錄影 |
| `voice/*.flac`、`voice/bank.json` | 人聲取樣庫（每個底聲一個檔）與索引 |
| `tools/build_voice_bank.py` | 產生取樣庫的程式 |
| `start.bat` | 啟動本機伺服器並開啟頁面（Windows） |
